Private. Sign in with a GitHub token that has write access to this site's repository.

How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → sorobedio.github.io.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy, and paste it here.

The token stays in this browser. It's never stored in the repository.
